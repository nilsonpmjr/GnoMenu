# Native exporter experiment

See [the prototype guide](../docs/native-exporter.md) for build commands, validation, evidence and limitations.

`gtk4-exporter.c` is an optional in-process library for Nautilus 50.4. It is not shipped in the GNOME extension ZIP and the normal installer does not load it. The private harness is the supported way to run this experiment.
